راهنمای پروژه — نسخه ماژولار option-ver16
=============================================

این پروژه، نسخهٔ تک‌فایلی option-ver16.html است که برای ویرایش آسان‌تر به ۱۵ فایل (۱ فایل HTML + ۱ فایل CSS + ۱۳ فایل JS) تفکیک شده است. هیچ منطقی تغییر نکرده؛ فقط کد به فایل‌های جداگانه منتقل شده است.

■ فهرست فایل‌ها و نقش هر فایل
---------------------------------------------
index.html ............... ساختار صفحه، مودال‌ها، پنل‌ها و ترتیب بارگذاری اسکریپت‌ها
css/main.css ............. تمام استایل‌ها (تم‌ها، جدول‌ها، مارکت‌مپ، واچ‌لیست و…)
js/00-theme-init.js ...... اعمال سریع تم ذخیره‌شده قبل از رندر (جلوگیری از پرش تم)
js/01-core.js ............ توابع کمکی ($، toNum، fmt، escapeHtml)، تاریخ جلالی، تجزیهٔ نام گزینه، ستون‌های واچ‌لیست و ابزارهای پایه
js/02-data.js ............ دریافت/به‌روزرسانی داده‌های بازار (fetch، خواندن فایل، وضعیت)
js/03-strategy.js ........ تنظیمات و منطق پارامترهای استراتژی (بازه، ytm، وثیقه و…)
js/04-chart-and-shell.js نمودار اصلی، رندر گزارش/جدول و مدیریت پنل‌ها (shell)
js/05-watchlist.js ....... واچ‌لیست (افزودن نماد، رفرش، ستون‌ها)
js/06-marketmap-themes.js مارکت‌مپ نقشهٔ بازار + تم‌های رنگی برنامه
js/07-popover.js ......... پاپ‌اور عمومی (نمایش جزئیات با کلیک/هاور)
js/08-covered-call.js .... منطق کامل استراتژی کاورد کال
js/09-till-tomorrow.js ... استراتژی «تا فردا» + نمودار مربوطه
js/10-manual-calc.js ..... ماشین‌حساب/محاسبات دستی اختیار معامله
js/11-saved-positions.js پوزیشن‌های ذخیره‌شده + محاسبهٔ نت/کامپاند
js/12-login.js ........... صفحه/گیت ورود (نام کاربری و رمز)

⚠️ هشدار مهم: این اسکریپت‌ها «classic script» هستند (نه module) و به‌ترتیب به هم وابسته‌اند. تغییر ترتیب تگ‌های <script> در index.html برنامه را خراب می‌کند (مثلاً توابع تعریف‌نشده یا خطای ReferenceError).

■ نحوهٔ اجرا
---------------------------------------------
فایل index.html باید از ریشهٔ خود پوشهٔ پروژه باز شود تا مسیرهای نسبی css/ و js/ درستresolve شوند. اگر index.html را از جای دیگری کپی یا جابه‌جا کنید، پوشه‌های css و js را همراه آن ببرید.

■ وابستگی‌های CDN (بدون تغییر نسبت به نسخهٔ اصلی)
---------------------------------------------
- فونت وزیرمتن (Vazirmatn) — cdn.jsdelivr.net
- کتابخانهٔ xlsx (خواندن/نوشتن اکسل)
- html2canvas (اسکرین‌شات)
- jsPDF (خروجی PDF)
برای اجرای آفلاین باید اتصال اینترنت (یا کش CDN) در دسترس باشد.

■ کدام بخش را کجا ویرایش کنم؟
---------------------------------------------
- ظاهر، رنگ‌ها و تم‌ها: css/main.css (متغیرهای تم در :root و بلوک‌های [data-theme])
- منطق کاورد کال و فرمول‌هایش: js/08-covered-call.js
- استراتژی «تا فردا»: js/09-till-tomorrow.js
- ستون‌های واچ‌لیست و توابع کمکی پایه: js/01-core.js
- خود واچ‌لیست (رفتار، رفرش، رندر): js/05-watchlist.js
- مارکت‌مپ: js/06-marketmap-themes.js
- دریافت داده‌ها: js/02-data.js
- نمودار اصلی و جدول گزارش: js/04-chart-and-shell.js
- محاسبات دستی: js/10-manual-calc.js
- پوزیشن‌های ذخیره‌شده: js/11-saved-positions.js
- نام کاربری/رمز ورود: js/12-login.js (مقادیر VALID_USER و VALID_PASS)

■ دربارهٔ تابع کمکی $
---------------------------------------------
تابع $ (معادل document.querySelector) فقط یک بار و در ابتدای js/01-core.js تعریف شده است؛ همهٔ فایل‌های بعدی از همان تعریف استفاده می‌کنند. هنگام ویرایش، تعریف دیگری از $ در فایل‌های دیگر اضافه نکنید (تعریف تکراری خطای SyntaxError: Identifier '$' has already been declared می‌دهد).
